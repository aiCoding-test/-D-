## 实现方式与时间安排

实现单机 P0：FastAPI 接收/查询/控制任务，PostgreSQL 保存状态并充当就绪队列，独立 Worker 协调步骤，子进程执行 MOCK 计算，本地持久卷保存产物。Jinja2 + 原生 JS 提供列表、流程、尝试时间线、失败恢复与资源看板。

流程为校验、抽帧、抠图、增强、图集/预览双分支、最终打包。GPU 与 AI 计算模拟，但真实执行子进程、数据库事务、自动重试、租约过期、文件校验和资源排队。

原预算为单人 20 小时，按“数据与接收 → 单步执行 → 故障恢复 → DAG/缓存 → 模拟资源/页面 → 验证交付”分配。本轮 AI 自动实现按同样次序推进，实际运行起止及测试耗时见 evidence，不把规划预算当成实际本人投入。首次 PyPI 构建和容器故障验证有真实等待时间。

## 长任务执行、状态和恢复

Task 表示固定业务请求，Step 表示逻辑节点，Attempt 表示一次计算尝试。Task 保存流程快照，Step 保存依赖与处理器版本，Attempt 保存 Worker、epoch、fence、租约、时间及错误。

API 提交在 DB 成功后返回 202；请求幂等，浏览器/API 生命周期不控制任务。Worker 短事务领取后再启动计算，心跳默认 5 秒、租约 30 秒。控制循环与计算分离；独立无 DB 看门狗避免数据库/DNS 阻塞时继续无限计算。

临时错误每步默认最多 3 次尝试，退避时刻和预算持久化；永久错误和稳定 OOM 不盲目重试。失联尝试记 LOST，旧令牌无法续租、上报进度或完成；子进程仍持有共享 flock 时资源隔离，不立即复用。

人工恢复增加 epoch 并保留有效成功步骤和全部旧历史；损坏祖先及后代重做。支持超时、取消和控制命令幂等。取消先撤销执行授权并隔离资源，进程物理退出可以稍后完成。

计算为至少一次尝试，可能重复。P0 恢复到步骤边界，未完成的当前步骤可从头重做，没有任意 GPU 内核或模型内部断点承诺。

## 步骤定义和依赖

固定 DAG：inspect → normalize_extract → remove_background → enhance_frames → {build_atlas, render_preview} → package。

所有直接父节点成功或缓存命中且产物有效，子节点才可领取。图集与预览可并行，打包等待两者。输入和参数不在线修改，修改业务语义新建 Task。各步骤仅纳入本步使用的参数，因此只改预览编码不会让上游 GPU 产物失效。

抠图、增强与编码分开，避免编码失败浪费昂贵推理。逐帧独立模型可扩展分块恢复；时序模型含上下文状态，需按镜头/片段定义边界。

## 持久化选择

| 数据 | 原因 |
| --- | --- |
| 原始输入摘要、参数、DAG、处理器版本 | 固定重试语义，代码升级不悄悄改写旧任务 |
| Task/Step 状态、Attempt 历史与 epoch | 查询、恢复和错误追溯的权威来源 |
| 租约、fence、当前尝试与资源持有者 | 排他授权，拒绝迟到写入，解释隔离 |
| 重试时间、次数与控制命令收据 | 重启不重置预算，重复恢复不增加两次代次 |
| 事务内业务事件、每任务 seq | 完整历史和无遗漏增量查询 |
| Artifact manifest、哈希、来源、CacheEntry | 校验中间结果并可解释地复用 |
| Worker 会话、最新模拟样本 | 在线、等待、资源新鲜度与占用查询 |

文件先私有写入、校验、不可变发布，再用 DB 条件事务提交引用。接受可清理孤立文件，不接受半文件变成功。进度、日志、Python 内存和 GPU 上下文都不是恢复检查点。

## 实际失败与修复

| 遇到的问题 | 原因 | 处理与复验 |
| --- | --- | --- |
| 默认 Docker 网络创建失败 | 本机已有很多项目，默认地址池耗尽 | 只为本项目指定独立网段，未删除其他网络；服务已启动 |
| 首次真实停库测试超过 HTTP 超时 | Docker 服务名消失时 DNS 等待可能超过普通连接超时 | 增加解析/连接边界及独立租约看门狗，使用直连本地 HTTP 客户端；停库 API 503、过期接续复验通过 |
| 扩展资源隔离测试失败一次 | 新断言引用的测试 Worker 尚未赋值，属于测试代码错误 | 修正初始化顺序；最终完整集成回归通过 |
| 早期迁移引用当前 ORM 定义 | 后续改模型可能改变旧 revision 的行为 | 冻结 0001.sql；专用测试库 downgrade/upgrade 后回归通过 |
| 预览 JSON 模式与初版 SVG 行为不同 | 修改输出需改变缓存身份 | 新处理器版本写入冻结 spec，保留旧版本兼容，定向缓存回归 |
| 初版 TestClient 有弃用警告 | 锁定 Starlette 提示后续改用 httpx2 | 当前兼容可运行，保留警告；不为无关 API 迁移扩大范围 |

小时级演进保留短租约，增加业务超时、带哈希的帧块检查点、流式产物 IO、存储/日志容量预算与长跑验证。真实 GPU 需设备绑定、NVML 与清理验证；多机前更换共享/对象存储并重验资源故障域。
